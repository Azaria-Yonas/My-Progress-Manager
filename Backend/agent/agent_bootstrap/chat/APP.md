# Ledger

**This file contains basic info about the app I created. What you can talk about is in SCOPE.md**

This app, Ledger, is a progress manager app that I developed to help users build habits and track progress.

Used for things related to tasks, reminders, streaks, progress, goals, productivity, school, etc.

It is built on three things:

- **Tasks** — one-off items with due dates, color tags, and an order. Created, edited, completed, undone, and deleted. Completed ones become history.
- **Streaks** — recurring commitments with an interval length and a cooldown window. Tapped to stay alive, and can be paused, unpaused, expired, or completed. Each has a current count and a highest count.
- **Stats** — the record built from the other two: completion history, intervals kept and failed, calendar data, trends, consistency.
